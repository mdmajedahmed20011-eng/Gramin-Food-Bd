# Mirror Site Project

https://pfecglobal.com.bd/ — এই পুরো ওয়েবসাইটটি আমাদের নতুন ওয়েবসাইটে সম্পূর্ণভাবে পুনর্নির্মাণ করো। মূল ওয়েবসাইটের সবকিছু একই রাখবে—কোনো গুরুত্বপূর্ণ page, section, content structure, feature বা functionality বাদ যাবে না।

Requirements

পুরো website structure ও sitemap একই রাখো

All pages, all sections, all subsections সম্পূর্ণ recreate করো

Header, navigation, mega-menu/dropdowns ও footer একইভাবে রাখো

প্রতিটি page-এর layout, content hierarchy, cards, buttons, forms ও CTA একই রাখো

একই images, icons, logos, illustrations ও visual assets ব্যবহার/রিপ্লিকেট করো যেখানে বৈধভাবে করা সম্ভব

Typography, spacing, grid, colors, borders, shadows, radius ও visual hierarchy যতটা সম্ভব accurately reproduce করো

সকল internal links, navigation এবং CTA functional রাখো

Forms, dropdowns, search, course/destination sections এবং অন্যান্য interactive elements কাজ করতে হবে

Responsive design সম্পূর্ণভাবে recreate করো—desktop, tablet ও mobile

Existing animations, hover effects, sliders, transitions ও interactive behavior replicate করো

SEO-friendly URL structure, metadata, semantic HTML এবং accessibility বজায় রাখো

কোনো placeholder page বা অসম্পূর্ণ section রাখা যাবে না

Website-এর overall UX ও information architecture মূল সাইটের সঙ্গে consistent রাখো

প্রথমে মূল ওয়েবসাইটের সম্পূর্ণ page-by-page এবং section-by-section audit করো। তারপর সেই structure অনুযায়ী আমাদের versionটি pixel-accurate, production-ready এবং fully responsive হিসেবে তৈরি করো।

মূল লক্ষ্য: দেখতে, navigate করতে এবং ব্যবহার করতে মূল PFEC Global Bangladesh website-এর equivalent experience তৈরি করা—শুধু আমাদের নতুন implementation/codebase-এ।  note:no backhand
